# Інформаційна система догляду за міськими зеленими насадженнями
Клієнт-серверна кросплатформенна інформаційна система для обліку міських зелених насаджень, проведення оглядів, формування заявок на роботи з контролем життєвого циклу та призначення нарядів. Через графічний інтерфейс JavaFX користувач може переглядати та редагувати дані (CRUD), відстежувати розрахунок інтегрального показника ризику, змінювати стани заявок та виконувати фоновий імпорт даних із CSV-файлу без блокування інтерфейсу. Прямого доступу клієнта до бази даних немає - усі операції проходять через HTTP/JSON та серверні шари `Servlet` - `Service` - `DAO` - `MySQL`.
## Використані технології

* **Java 21** - основна мова програмування серверної та клієнтської частин.
* **Maven** - керування залежностями та складання модулів проєкту (server і client).
* **JavaFX** - графічний інтерфейс користувача та фонова обробка завдань.
* **Servlet API (javax.servlet-api 4.0.1)** та **Apache Tomcat 9.x** - серверна обробка HTTP-запитів та розгортання WAR-архіву.
* **MySQL** та **JDBC (MySQL Connector/J)** - реляційне зберігання даних і доступ до таблиць через DAO.
* **Jackson** - серіалізація та десеріалізація даних у форматі JSON.
* **JUnit 5** - автоматизоване модульне тестування бізнес-логіки серверної частини.
* **Git** - контроль версій та публікація репозиторію.

## Підготовка бази даних
1. Запустіть сервер MySQL наприклад, через XAMPP Control Panel та переконайтеся, що служба працює.
2. Відкрийте phpMyAdmin або інший SQL-клієнт і виконайте кореневий скрипт database.sql для створення бази даних, необхідних таблиць та початкових записів.
3. Перевірте наявність таблиць у базі даних та за потреби звірте параметри підключення у серверному класі підключення до БД (DBUtil) під локальне середовище.
# Запуск сервера
1. Перейдіть у каталог серверного модуля та зберіть WAR-архів командою cd server - mvn clean package
2. Скопіюйте сформований WAR-файл із каталогу server/target/ до каталогу webapps сервера Apache Tomcat 9.x.
3. Перевірте доступність GET-маршруту у браузері.
# Запуск JavaFX-клієнта
Перед запуском клієнта переконайтеся, що MySQL та Apache Tomcat 9.x запущені і сервер відповідає на запити.
1. Відкрийте термінал у каталозі client та виконайте mvn javafx:run.
2. Запускайте клієнт саме з каталогу client, щоб відносний шлях sample-data/trees.csv коректно визначався під час роботи застосунку. За потреби перевірте базовий URL сервера (BASE_URL) у HTTP-клієнті клієнтської частини.
# Тестування
Модульні тести JUnit 5 розташовані у каталозі server/src/test/java та перевіряють ключові правила предметної логіки (розрахунок інтегрального показника ризику, допустимі й заборонені переходи станів життєвого циклу, валідацію даних та розбір рядків) без потреби запускати Tomcat, MySQL або JavaFX.
Для запуску тестів виконайте у каталозі server: mvn clean test. Очікуваний результат - успішне проходження всіх тестів і статус BUILD SUCCESS.
# CSV-імпорт
* Шлях до файлу: client/sample-data/trees.csv
* Кодування та формат: UTF-8, роздільник полів - крапка з комою (;), перший рядок - заголовок.

Як виконати: запустіть систему, відкрийте відповідну вкладку в JavaFX-клієнті та натисніть кнопку імпорту. Читання файлу та надсилання даних на сервер через HTTP виконуються у фоновому потоці (Task) з оновленням ProgressBar, текстового статусу та записом подій у Logger.

Якщо серверна логіка/БД не фільтрують повтори автоматично, повторний запуск імпорту того самого CSV-файлу з тими самими даними може створити дублікати записів. Перед повторною перевіркою контролюйте початковий стан даних у базі.
